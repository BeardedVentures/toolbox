Guide 03-05

Install your first MCP server in Claude Desktop

A copy-and-paste walkthrough for Mac and Windows, plus fixes for the three things that usually go wrong.

10 min readIntermediateBuild your ownUpdated Nov 1, 2026

We’ll install Sequential Thinking first because it reads no files and no web pages, so it’s a low-stakes way to learn the steps. Then you can add any other tool from our MCP library the same way.

Menu names below were checked against the MCP project’s own guide on Nov 1, 2026. App menus move; if something has changed, that guide (linked under Sources) has the current steps.

What you need

  • Claude Desktop (the downloadable app, not the website). Get it from claude.ai/download.
  • Node.js version 24 or newer, from nodejs.org. Click through the installer with the defaults. To check what you have, open Terminal (Mac) or Command Prompt (Windows) and type node --version.
  • Some tools need uv instead; their page says so.

Step 1: open the config file

Open Claude Desktop’s Settings from the Claude menu (on a Mac, that’s in the menu bar at the top of the screen, not the settings inside a chat). Go to Developer → Edit Config. A file called claude_desktop_config.json opens in a text editor. It may be empty, or have {} in it.

Back it up before you change anything. Select everything in the file, copy it, and paste it into a new note or text file you keep. If the file was empty, note that too. That copy is your undo.

Step 2: paste the config

If the file is empty or just {}, replace everything in it with the block below. If it already has an mcpServers section, add the sequential-thinking entry inside that section instead (see “Adding a second tool”).

{
  "mcpServers": {
    "sequential-thinking": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sequential-thinking"]
    }
  }
}

On Windows, the server’s README runs npx through cmd:

{
  "mcpServers": {
    "sequential-thinking": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "@modelcontextprotocol/server-sequential-thinking"]
    }
  }
}

Save the file.

Step 3: restart Claude completely

Closing the window isn’t enough. Quit the app (Mac: Claude menu → Quit; Windows: right-click the tray icon → Quit), then open it again.

Step 4: check it worked

Start a new chat, click the + button in the message box (Add files, connectors, and more) and open Connectors. You should see sequential-thinking listed. Ask: “Use sequential thinking to plan a small product launch.” Claude may ask permission before it uses the tool.

Adding a second tool

Each tool goes inside mcpServers, separated by a comma:

{
  "mcpServers": {
    "sequential-thinking": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sequential-thinking"]
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/YOU/Desktop/AI-Shared"]
    }
  }
}

How to undo it

Quit Claude completely. Open the config file again (Developer → Edit Config), replace everything in it with the backup you saved in Step 1, save, and reopen Claude. To remove just one tool, delete its block instead, and check the commas between the blocks that are left.

When it doesn’t work

  1. The tool doesn’t show up. Most often it’s a typo in the file: a missing comma, quote or bracket. Paste your config into any free “JSON validator” site to find it. Then quit and reopen Claude again.
  2. “npx” or “uvx” not found. Node.js or uv isn’t installed, Node.js is older than version 24, or Claude was open while you installed it. Install or update, then restart your computer.
  3. Windows paths. Inside the config, write backslashes twice: C:\\Users\\you\\Desktop\\AI-Shared. If npx still fails on Windows, change "command": "npx" to "command": "cmd" and put "/c", "npx", at the start of the args list.

Claude Desktop also writes logs you can check. They’re in ~/Library/Logs/Claude on a Mac and %APPDATA%\Claude\logs on Windows: mcp.log covers connections in general, and mcp-server-NAME.log holds each server’s own errors.
