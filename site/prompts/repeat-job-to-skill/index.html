Prompt 01-17

Teach Claude a job you do the same way every time

Describe a task you do the same way every time. Get a ready-to-install SKILL.md that Claude loads on its own whenever that task comes up.

AdvancedTestedClaudeTech & developersSolo operator
Prompt
Write an Agent Skill (a SKILL.md file) for a job I repeat.

The job: [THE JOB]
How I do it today, step by step: [HOW YOU DO IT TODAY]
A finished example I was happy with: [A GOOD FINISHED EXAMPLE]

Rules for the file:
- Start with YAML front matter containing only `name` (lowercase letters, numbers and hyphens, 64 characters max, and not containing the words "claude" or "anthropic") and `description` (under 200 characters so it also uploads to claude.ai, saying what the skill does AND the exact situations that should trigger it, in the words I'd actually use when asking).
- Then Markdown: a one-line purpose, the inputs it needs (and what to ask me if one is missing), numbered steps, the output format, and a short "Don't" list.
- Put my finished example at the end under "Example output".
- Keep the whole file under 400 lines. No filler, no motivational intro.

Before writing, ask me up to three questions if anything about the job is unclear. After writing, list two requests that SHOULD trigger the skill and one that should NOT, so I can test the description.
Fill in
  • [THE JOB]
  • [HOW YOU DO IT TODAY]
  • [A GOOD FINISHED EXAMPLE]

Paste your own words, not client records, passwords or anything confidential. What you paste goes to the AI company.

What it actually does

Tested in Claude · Nov 1, 2026

Run by Claude while building this page. The example below is from that run, trimmed.

We filled in
THE JOB: Writing a repair estimate for a residential plumbing call. HOW YOU DO IT TODAY: Get customer name and address and what's wrong. List parts with prices from my supplier sheet. Add 15% markup on parts. Labor is hours × $115. Add a $65 trip charge. Note it's good for 30 days. Send as a PDF. A GOOD FINISHED EXAMPLE: "Estimate — R. Hollis, 14 Larkspur Ct. Replace kitchen faucet. Parts: faucet $142.00, supply lines (2) $18.00, marked up 15% = $184.00. Labor 1.5 h × $115 = $172.50. Trip $65.00. Total $421.50. Valid 30 days."
It came back with (trimmed)
Questions first: 1. Will you paste part prices each time? 2. Is the $65 trip charge ever waived? 3. Should sales tax appear? *Simulated answer:* "I paste prices. Trip charge is waived if they approve same day, just add a note. No tax line." ``markdown --- name: plumbing-repair-estimate description: Writes residential plumbing repair estimates: parts at 15% markup, labor at $115/h, $65 trip charge. Use when I say "write an estimate", "quote this job" or "price this repair". --- # Plumbing repair estimate Turns job notes and a parts list into a customer-ready estimate in my format. ## Inputs - Customer name and service address (ask if missing) - Parts with prices (ask me to paste them; never look up or guess a price) - Labor hours (ask if missing) ## Steps 1. List each part with price; total them, then add 15% markup. 2. Labor = hours × $115. 3. Add the $65 trip charge with the note "Waived if approved today." … ## Don't - Don't invent parts, prices or hours. - Don't add a tax line. … `` Test it: should trigger: "Write up an estimate for the Hollis faucet job." / "Price this water heater swap, parts below." Should NOT: "What do plumbers usually charge per hour around here?"

Where it falls short

  • Getting the description to 177 characters meant dropping a looser trigger (pasting a parts list with no request), so a vague ask may not load the skill.
  • The pasted example at the end predates the same-day waiver note, so the Example output and step 3 don't quite match.
  • The old workflow ends with sending a PDF; the skill can only produce one where file creation is turned on, so in plain chat it stops at text.

When to use it

You’ve explained the same process to an AI more than twice: how you write a quote, format a report, review a contract clause, prep a job file. A skill saves that explanation once and Claude pulls it in by itself when the task shows up.

Where it goes

  • Claude apps (claude.ai, desktop): put SKILL.md in a folder with the same name as the skill, zip the folder, then upload it in Claude’s Skills settings. Code execution must be on; Anthropic’s help article has the current menu path.
  • Claude Code: save it as .claude/skills/<name>/SKILL.md in your project, or ~/.claude/skills/<name>/SKILL.md for every project.

Menu names shift as the apps update. Checked Nov 1, 2026 against Anthropic’s help article Use Skills in Claude and the Claude Code skills docs.

Why it works

Claude decides whether to load a skill from its description alone, so the prompt forces a description written in your own trigger words, then makes you test it with requests that should and shouldn’t fire.
