MCP tool 02-02

Get dates and time zones right when you schedule

Gives Claude your computer's current time and exact time-zone conversions, so "3pm my time is what in London?" comes out right.

Heads-up · what this can touch

Only your computer's clock and time-zone setting. No files, no web.

You'll need: Claude Desktop and uv, a free Python tool installer (from astral.sh/uv).

claude_desktop_config.json
{
  "mcpServers": {
    "time": {
      "command": "uvx",
      "args": ["mcp-server-time"]
    }
  }
}

Where it falls short

  • It has only two tools, one that gets the current time and one that converts a time between zones.
  • Conversion takes a single 24-hour time like 15:00, and there's no tool for date math; for "45 days from today" it supplies today's date and Claude still does the counting.
  • If you set a time zone yourself, it has to be the exact official name with the right capitals, such as America/Chicago, not america/chicago.

Why you’d want it

AI models have no clock of their own. Many apps pass today’s date into the chat, but if you schedule across time zones, a tool that reads your computer’s clock and converts times exactly removes a common source of mistakes.

Set it up

  1. Install uv using the one-line installer at astral.sh/uv (Terminal on Mac, PowerShell on Windows).
  2. Open Claude Desktop’s Settings from the Claude menu (on a Mac, the menu bar at the top of the screen, not the settings inside a chat), then Developer → Edit Config. Paste the config above and save. If the file already has an mcpServers section, add time inside it.
  3. Fully quit and reopen Claude Desktop.
  4. Click the + button in the message box, open Connectors, and check that time is listed.

It picks up your computer’s time zone by itself. If it gets it wrong, add "--local-timezone=America/Chicago" after "mcp-server-time" in the args, using your own zone’s exact name (for example America/New_York or America/Los_Angeles).

Try these

  • “What time is it right now in Tokyo?”
  • “If I call at 15:00 my time, what time is that for someone in London?”

Good to know

  • We haven’t installed and run this one ourselves yet. We checked the setup against the maker’s README on Nov 1, 2026.
  • The MCP project calls its servers reference implementations: educational examples, not production-ready solutions.
