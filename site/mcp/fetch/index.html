MCP tool 02-04

Let Claude read a web page you point it to

Let Claude Desktop pull up a web page and read it, so you can say "summarize this link" or "compare these two product pages."

Beginner Not yet tested by us
StatusNot yet tested by us
Made byModel Context Protocol project
Works withClaude Desktop, Claude Code

CheckedNov 1, 2026

We haven't run this one ourselves yet. Everything on this page comes from the maker's own documentation, checked on the date above.

Heads-up · what this can touch

Reads public web pages you or Claude point it at. It can't log in to sites or see anything behind a password, and current versions refuse private and intranet addresses by default (older installs may not, so keep it updated).

You'll need: Claude Desktop and uv, a free Python tool installer (from astral.sh/uv). It needs Python 3.10 or newer, which uv takes care of.

claude_desktop_config.json 
{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"]
    }
  }
}

Back up first. Before you paste this in, open the config file (Claude Desktop: Settings, then Developer, then Edit Config), copy everything in it, and save that copy somewhere. If the file is empty, note that.

To undo. Quit Claude completely, put your saved copy back in the config file (or delete just this tool's block), save, and reopen Claude.

Where it falls short

  • It follows a site's robots.txt for pages Claude decides to fetch, so some sites will refuse it by design.
  • It returns about 5,000 characters at a time by default, so a long page comes in several chunks.
  • It turns the page's HTML into text and doesn't run a browser, so pages built by JavaScript may come back empty (our reading of the README, not something we've tested).

Why you’d want it

Claude’s web search is good for finding things. Fetch is for reading one specific page closely: a competitor’s pricing, a long article, a supplier’s spec sheet.

Set it up

  1. Install uv. On Mac, open Terminal and run the one-line installer shown at astral.sh/uv. On Windows, use the PowerShell line from the same page.
  2. Open Claude Desktop’s Settings from the Claude menu (on a Mac, the menu bar at the top of the screen, not the settings inside a chat), then Developer → Edit Config. Paste the config above and save. If the file already has an mcpServers section, add fetch inside it instead of replacing it.
  3. Fully quit and reopen Claude Desktop.
  4. Click the + button in the message box, open Connectors, and check that fetch is listed.

If it times out on Windows, the README suggests adding this inside the fetch entry: "env": {"PYTHONIOENCODING": "utf-8"}.

Try these

  • “Fetch [LINK] and give me the five things a customer would care about.”
  • “Compare the pricing pages at [LINK 1] and [LINK 2] in a table.”

Good to know

  • Some sites block automated readers. That’s their right; if a page won’t load, open it yourself and paste the text.
  • We haven’t installed and run this one ourselves yet. We checked the setup against the maker’s README on Nov 1, 2026.
  • The MCP project calls its servers reference implementations: educational examples, not production-ready solutions.
