MCP Tools

Plug AI into your stuff. Every tool says up front what it can touch.

New to this? Read the short explainer first →

MCP tool 02-01 Connect Gmail, Drive and Calendar to Claude with a sign-in The easiest way in. Connect Google Drive, Gmail, Calendar and other apps to Claude by signing in. Nothing to install, no files, no code. BeginnerNot yet tested by us Set it up →

Heads-up · what this can touch Only the apps you choose to connect, signed in as you. Each one gets whatever access its app asks for when you connect it, so read that list before you say yes. You can disconnect any of them in Claude's settings.

MCP tool 02-02 Get dates and time zones right when you schedule Gives Claude your computer's current time and exact time-zone conversions, so "3pm my time is what in London?" comes out right. BeginnerNot yet tested by us Set it up →

Heads-up · what this can touch Only your computer's clock and time-zone setting. No files, no web.

MCP tool 02-03 Help Claude plan big, messy problems step by step A thinking scratchpad that helps Claude break big, messy problems into steps, revise as it goes, and show its reasoning. BeginnerNot yet tested by us Set it up →

Heads-up · what this can touch Reads no files and no web pages. It runs a small program on your computer that structures Claude's reasoning and writes those steps to Claude Desktop's log files unless you turn logging off.

MCP tool 02-04 Let Claude read a web page you point it to Let Claude Desktop pull up a web page and read it, so you can say "summarize this link" or "compare these two product pages." BeginnerNot yet tested by us Set it up →

Heads-up · what this can touch Reads public web pages you or Claude point it at. It can't log in to sites or see anything behind a password, and current versions refuse private and intranet addresses by default (older installs may not, so keep it updated).

MCP tool 02-05 Let Claude work with files in one folder on your computer Let Claude Desktop read and organize files in one folder you choose. Good for sorting downloads, tidying file names or pulling notes out of a folder of text files. BeginnerNot yet tested by us Set it up →

Heads-up · what this can touch Only the folders you list in the config. Inside those, it can read, create, move and edit files. Nothing outside them, and it has no delete-file tool.

MCP tool 02-06 Have Claude remember people and preferences in your own file Gives Claude Desktop a simple notes file it can write to and read from, so it remembers people, preferences and project facts between chats. IntermediateNot yet tested by us Set it up →

Heads-up · what this can touch A single notes file on your own computer. When Claude uses a note, that note goes into your chat, and your chat goes to Anthropic like any other message.
