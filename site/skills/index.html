Skills

Explain the job once. It remembers.

A skill is a saved set of instructions for one kind of job. In Claude it's a SKILL.md file you upload once; in other apps, paste the same text into a custom assistant. New to this? Turn your own process into a skill.

Skill 01 Build a one-page site that turns QR scans into leads A build guide for an assistant: a fast, phone-first landing page with a short form, a backup copy of each lead, and spam protection. Built from a real realtor lead page. IntermediateTested in Claude Get the skill →
Skill 02 Decide what your AI can do without asking you A one-page permission table for any AI agent: what it may do alone, what it checks with you, and what it must never do, with the stricter rule always winning. IntermediateTested in Claude Get the skill →
Skill 03 Draft posts and emails that say who they're for A writing setup for marketing drafts. Every draft opens with who it's for and what it should get them to do, and ends with what the AI assumed or couldn't check. BeginnerTested in Claude Get the skill →
Skill 04 Get answers you can check, with the sources listed An assistant setup for questions where being current matters. It answers only from what it finds in a live search, links every source, and says so when it finds nothing. BeginnerTested in Claude Get the skill →
Skill 05 Give your AI a memory that doesn't get messy A memory setup for assistants you use every day: one short, capped core note that's always loaded, and everything else in dated notes it looks up when needed. AdvancedTested in Claude Get the skill →
Skill 06 Pick up a long AI task right where you left off A checkpoint file the AI updates at the end of every session on a long job, so you (or a fresh chat) can resume in one read instead of re-explaining everything. IntermediateTested in Claude Get the skill →
Skill 07 Stop your AI assistant from leaving work half done A rule set for AI agents and assistants that run tasks for you. Every turn ends in one of three clear states, and nothing is called done without proof. IntermediateTested in Claude Get the skill →
