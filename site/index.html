How we keep it honest

Nothing goes up untested.

Or if it does, it says so in plain words. Read the checklist every item has to pass.

  1. 1

    Run it for real

    Every prompt and skill is run with a realistic example. The page shows what we put in and what came back, trimmed.

  2. 2

    Write down where it fails

    Each page lists where it falls short. If testing found a problem, we fixed the prompt and ran it again.

  3. 3

    No made-up numbers

    No "saves 10 hours a week". Facts about apps and plans link to the company's own page, with the date we checked.

Let your AI reach your files, the web and more

MCP servers let an assistant like Claude do things, not just talk. Each page says exactly what the tool can touch, where it falls short, and whether we've tested it ourselves yet.

MCP tool 02-01Connect Gmail, Drive and Calendar to Claude with a sign-inThe easiest way in. Connect Google Drive, Gmail, Calendar and other apps to Claude by signing in. Nothing to install, no files, no code.BeginnerNot yet tested by usSet it up →

Heads-up · what this can touchOnly the apps you choose to connect, signed in as you. Each one gets whatever access its app asks for when you connect it, so read that list before you say yes. You can disconnect any of them in Claude's settings.

MCP tool 02-04Let Claude read a web page you point it toLet Claude Desktop pull up a web page and read it, so you can say "summarize this link" or "compare these two product pages."BeginnerNot yet tested by usSet it up →

Heads-up · what this can touchReads public web pages you or Claude point it at. It can't log in to sites or see anything behind a password, and current versions refuse private and intranet addresses by default (older installs may not, so keep it updated).

MCP tool 02-05Let Claude work with files in one folder on your computerLet Claude Desktop read and organize files in one folder you choose. Good for sorting downloads, tidying file names or pulling notes out of a folder of text files.BeginnerNot yet tested by usSet it up →

Heads-up · what this can touchOnly the folders you list in the config. Inside those, it can read, create, move and edit files. Nothing outside them, and it has no delete-file tool.
